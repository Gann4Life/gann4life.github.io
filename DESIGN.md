# Portfolio v3 — Plan

One site for everything: software, games, 2D, 3D, animation, music.
Static, git-based, no backend to maintain or patch.

The spec is split into one file per section under `docs/`. Read only the
sections the task needs; "section N" anywhere in the repo means `docs/N-*.md`.

| § | File | Read when |
|---|---|---|
| 1 | [Stack](docs/1-stack.md) | Choosing tools, hosting, image pipeline, CMS |
| 2 | [Content model](docs/2-content-model.md) | Schema, frontmatter, AI-built and fork rules |
| 3 | [Pages](docs/3-pages.md) | Adding or changing routes |
| 4 | [Media rendering](docs/4-media.md) | Viewers, players, embeds per `kind` |
| 5 | [Phases](docs/5-phases.md) | Picking the next step, checking progress |
| 6 | [Content rules](docs/6-content-rules.md) | Before writing any claim, credit, or NDA-adjacent entry |
| 7 | [Lessons](docs/7-lessons.md) | Weighing a dependency or architecture change |
| 8 | [Open decisions](docs/8-open-decisions.md) | Before deciding anything listed there |
