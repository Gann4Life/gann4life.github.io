# 7. Lessons from previous versions

- Don't depend on third-party APIs for core content (v2 broke risk).
- No server-side code to maintain (v1 PHP became a liability).
- No ads, no dead counters, no hotlinked media. One deliberate exception: appearance URLs ([section 8](8-open-decisions.md) "Site appearance"), which can only degrade to today's look and are checked weekly.
- Components instead of copy-pasted markup.
- Write a real README.
